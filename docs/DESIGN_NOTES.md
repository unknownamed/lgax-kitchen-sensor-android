## Android에 적용한 것

| 기준 | 앱 적용 |
| --- | --- |
| 바탕과 표면 | `#F5F5F7` 바탕과 흰색 카드 |
| 글자 | `#1D1D1F` 본문, `#6E6E73` 보조 설명 |
| 동작 색상 | `#0066CC` 시작·기록 버튼과 내보내기 테두리 |
| 카드 | 18dp 둥근 모서리, 그림자 없음 |
| 버튼 | 50dp 이상 터치 영역, 둥근 캡슐, 누름·초점·비활성 상태 |
| 여백 | 화면 20dp, 카드 20dp, 카드 간격 16dp |
| 글자 계층 | 제목 32sp, 지수 64sp, 센서값 24~32sp, 설명 13~14sp |

Apple 웹페이지의 사진 중심 구성에서 색상, 글자 계층, 여백과 버튼 형태를 가져왔다. 측정 앱에서는 큰 지수 아래에 연결·센서·기록을 세로로 배치한다. 글자 확대 때 내용이 늘어나도록 버튼 높이와 카드 높이는 고정하지 않는다.

글꼴은 Android 기본 sans-serif를 사용한다. SF Pro 파일이나 Apple 로고를 포함하지 않는다. 지수나 센서값을 장식용으로 채우지 않고, 실제 값이 없으면 대시 또는 미측정으로 표시한다.

README의 실행 화면은 APK 원본 캡처다. 구성 그림과 시나리오는 개념 설명 이미지이며, 와이어프레임의 `[측정값]`은 자리 표시다.

## 코드별 책임

| 파일 | 맡은 일 |
| --- | --- |
| `MainActivity` | 화면 생명주기, 버튼 동작, 시스템 파일 선택기, 백그라운드 파일 작업 |
| `DashboardView` | 화면을 한 번 연결하고 바뀐 표시만 갱신 |
| `MeasurementController` | 휴대폰 센서 등록·해제, 외부 센서 폴링, 지난 측정 회차 응답 제외 |
| `SensorHttpClient` | 주소 검사, HTTP 요청 시간·응답 크기 제한 |
| `MeasurementState` | 측정값 보관, 단조 증가 시간 기준 유효 기간 |
| `SensorReading` | 외부 센서 범위 검사와 임시 지수 계산 |
| `ReadingSnapshot` | 기록 버튼을 누른 시점의 유효한 값 |
| `RecordStore` | CSV 쓰기·읽기·복사와 기록 요약 |

외부 측정값은 응답에 들어 있는 `sample_age_ms`와 수신 뒤 경과 시간을 합쳐 10초를 넘으면 제외한다. 화면을 벗어나면 센서 등록과 폴링을 멈춘다. CSV 읽기·쓰기·내보내기는 별도 파일 스레드에서 실행한다.
