## 현재 Android 화면

v0.3.0은 [LG 공식 디자인 시스템](https://www.lg.com/global/our-identity/design-system/)의 둥근 제품 형태와 [LG 공식 색상 가이드, 37쪽](https://www.lg.com/us/wonderbox/Wonderbox-GuidelinesSpecs.pdf)의 LG Red·Active Red·Warm Gray를 참고한다. 접시와 물방울로 만든 자체 심볼을 사용한다. 위의 Apple 분석 파일은 이전 디자인의 참고 기록으로 보관한다.

| 기준 | 앱 적용 |
| --- | --- |
| 바탕과 표면 | 따뜻한 회색 `#F6F3EF`, 흰색 카드와 연한 장밋빛 지수 카드 |
| 글자 | `#262626` 본문, `#716F6A` 보조 설명 |
| 동작 색상 | LG Red `#A50034` 시작·기록 버튼, 지수와 내보내기 테두리 |
| 강조 | Active Red `#FD312E` 진행 표시, 연한 붉은 상태 배지 |
| 카드 | 22dp 둥근 모서리, 얇은 테두리와 센서별 안쪽 표면 |
| 버튼 | 48dp 이상 높이, 짧은 측정 버튼, 가로 기록·내보내기 버튼, 글자는 12~15sp 안에서 한 줄로 맞춤 |
| 여백 | 화면 20dp, 카드 16dp, 센서 칸 12dp, 카드 간격 12dp |
| 글자 계층 | 제목 28sp, 지수 52sp, 센서값 24~28sp, 기록 개수 28sp, 설명 13~14sp |
| 앱 아이콘 | 적응형 아이콘, 둥근 마스크와 Android 13 단색 아이콘 지원 |

큰 지수 아래에 연결·센서·기록을 세로로 배치한다. 상단에 자체 아이콘과 짧은 제품 설명을 표시하고, 팀명과 작성자는 하단에 둔다. 연결 상태를 짧은 배지와 상세 안내로 보여 준다. 주소 입력칸에는 화면에 계속 보이는 레이블과 예시 주소를 연결한다. 글자 확대 때 내용이 늘어나도록 버튼 높이와 카드 높이는 고정하지 않는다.

글꼴은 Android 기본 sans-serif를 사용한다. 지수나 센서값은 유효한 측정값으로만 표시하고, 실제 값이 없으면 대시 또는 미측정으로 표시한다.

README의 실행 화면은 APK 원본 캡처다. 구성 그림과 개발용 샘플 실행은 온도 25°C, 습도 50%, 빛 ADC 1000과 임시 지수 57을 일관되게 맞춘다. 휴대폰 조도 320 lx, 움직임 0.12 m/s², 기록 3개도 화면 확인용 데이터다. 실제 센서 모드와 실물 검증 로그에는 샘플 수치를 넣지 않는다.

v0.4.0에서는 장치 구성 그림을 실제 앱의 지수·기록 카드 안에 배치한다. 개발용 APK의 화면 검증에서는 ‘샘플 데이터’와 ‘샘플 기록’ 표시를 사용하고 일반 측정 CSV와 분리한다. 일반 실행은 실제 센서 모드로 시작한다. 구성도·와이어프레임·시나리오에도 같은 장치 그림을 넣는다.

v0.4.1의 장치 그림은 제공된 ESP32-C6-WROOM-1 보드 사진을 기준으로 긴 검은색 기판·두 USB-C 포트·핀 헤더 형태를 맞춘다. 설치 전원은 AA 3개 홀더와 5V 승압 모듈이며, 설치 그림에는 USB 전원선을 연결하지 않는다. 기준 보드 사진은 문서에 따로 보관하고, 앱에는 같은 구성의 투명 배경 그림을 사용한다.

와이어프레임의 네 단계 모두 공통 로고와 붉은 버튼을 사용한다. 저장 목업에는 CSV 예시 파일 3개와 문서 아이콘을 넣는다. 실제 Android 시스템 파일 선택기의 테마나 파일 목록을 앱이 바꾼 것으로 표시하지 않는다. 실제 앱에는 접시·휴대폰·파일 아이콘으로 지수와 각 카드의 역할을 구분한다.

## 코드별 책임

| 파일 | 맡은 일 |
| --- | --- |
| `MainActivity` | 화면 생명주기, 버튼 동작, 시스템 파일 선택기, 백그라운드 파일 작업 |
| `DashboardView` | 화면을 한 번 연결하고 바뀐 표시만 갱신 |
| `MeasurementController` | 휴대폰 센서 등록·해제, 외부 센서 폴링, 지난 측정 회차 응답 제외 |
| `SensorHttpClient` | 주소 검사, HTTP 요청 시간·응답 크기 제한 |
| `MeasurementState` | 측정값 보관, 단조 증가 시간 기준 유효 기간 |
| `SensorReading` | 외부 센서 범위 검사와 임시 지수 계산 |
| `ReadingSnapshot` | 기록 버튼을 누른 시점의 유효한 값 |
| `RecordStore` | CSV 쓰기·읽기·복사와 기록 요약 |

외부 측정값은 응답에 들어 있는 `sample_age_ms`와 수신 뒤 경과 시간을 합쳐 10초를 넘으면 제외한다. 화면을 벗어나면 센서 등록과 폴링을 멈춘다. CSV 읽기·쓰기·내보내기는 별도 파일 스레드에서 실행한다.
