v0.1.1에서 연결·지수·센서·기록 카드와 버튼 스타일을 추가했다. 데이터가 없으면 기록 버튼을, 저장된 기록이 없으면 내보내기 버튼을 비활성화한다.

v0.2.0에서 연회색 바탕, 흰색 카드, 파란 캡슐 버튼과 큰 지수 표시를 적용했다. 기존 CSV 열과 버튼 동작을 유지하며, 응답의 측정 경과 시간도 외부 값 만료에 반영한다. 파일 내용이 바뀌지 않았으면 기록 요약을 다시 읽지 않고 한 행만 추가한다.

## 기기에서 확인할 것

- [ ] ESP32와 DHT22·LDR 실제 배선 및 업로드
- [ ] 휴대폰이 인터넷 없는 ESP32 Wi-Fi 연결을 유지하는지 확인
- [ ] 조도·가속도 센서가 있는 기기와 없는 기기에서 확인
- [ ] 기록 후 CSV 저장·취소·재시작 흐름 확인
- [ ] ESP32 연결을 끊었을 때 오래된 값이 기록되지 않는지 확인
- [ ] 앱을 나갔다 돌아오면 측정이 중지되어 있는지 확인
- [ ] 건조대 위치·환기·접시 재질별로 수치 비교
- [ ] 임시 점수가 실제 물기와 관련이 있는지 확인

작업할 때는 남은 작은 항목부터 수정한다. 기기 확인을 하지 않은 항목은 체크하지 않는다.
